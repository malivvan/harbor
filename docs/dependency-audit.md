## Codecs

- JSON: standard library.
- Gob: standard library.
- AES: standard library (`crypto/aes`, `crypto/cipher`).
- Vector points (`vec`): `github.com/malivvan/binco`, generated by `vec/gen`.

The `db` and `kv` codecs use only the standard library.

## Packages

- Public database API: `github.com/malivvan/storm/db`
- Bucket-oriented key/value store: `github.com/malivvan/storm/kv`
  (uses bbolt and codecs directly; no dependency on `db`)
- Query and index helpers: `github.com/malivvan/storm/q`,
  `github.com/malivvan/storm/index`
- Codecs: `github.com/malivvan/storm/codec`
- Vector database: `github.com/malivvan/storm/vec`
- File system: `github.com/malivvan/storm/fs`

## Nested modules and fixtures

- The module has no nested Go modules.
- All compatibility fixtures previously used for old-version testing have been
  removed. There is no legacy on-disk compatibility surface.
